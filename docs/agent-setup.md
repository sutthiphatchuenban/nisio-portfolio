# Admin Agent

The Agent supports OpenAI-compatible Chat Completions, Responses and Anthropic Messages with tool calling. Gemini can be configured through its OpenAI-compatible endpoint, and OpenCode Console/Go endpoints can be entered directly. Actual model and subscription capabilities vary by provider. It retains one conversation per admin, accepts one Cloudinary image, offers keyless public SearXNG search or supported provider-native search, reads administrative data, creates and updates projects, blog posts, categories, skills and videos, marks messages, creates meeting rooms, and updates supported site settings. Deletion and closing a meeting require an expiring one-time confirmation. A request ID prevents replaying the same submitted request; a separate new request is a new action.

Set a unique, stable `AGENT_ENCRYPTION_KEY` environment variable of at least 32 characters on every deployment sharing the database. Back up this key securely: changing it makes saved provider credentials unreadable. Apply database migrations using the project's normal deployment migration process, then restart the server. Do not add provider credentials or the encryption key to the public settings endpoint or source control.

In Settings → AI Agent, configure the HTTPS Base URL, API format, model ID and API key. The endpoint must resolve to public addresses and support IPv4; requests pin a validated address. Provider and search keys are encrypted at rest and are not returned to the browser. Connection and tool-calling tests use the saved connection and may incur provider charges. OpenCode Go documents that its service is designed for coding-agent traffic; the application identifies itself and sends a stable session header, but eligibility and permitted use remain subject to the provider's policies.

Context window is an approximate preflight limit rather than an exact tokenizer count. Max output tokens and reasoning mapping are sent to the chosen provider. Structured-output and video/PDF capability flags are metadata; video and PDF upload are not implemented. Other current limitations include one provider profile and one attached image at a time, no OpenCode Server adapter, no background jobs or streaming, no action rollback, and no multi-conversation UI. Anthropic and Responses adapters have been tested with mocked providers; the configured OpenCode endpoint passed real connection and tool-calling probes, but real content publication and image handling have not been tested.

Web searches use public SearXNG instances by default without an API key. Search queries are sent to the instance operators, and public availability, results, and rate limits can vary. If Native web search is enabled, the provider handles search instead and may charge for it.
